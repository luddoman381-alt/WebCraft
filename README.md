# WebCraft

Иммерсивный сайт студии WebCraft с каталогом услуг и админ-панелью.

- Этап 1 — 3D-главная (ноутбук + смартфон).
- Этап 2 — живой сайт на экране ноутбука и кинематографический переход в каталог.
- Этап 3 — сервер, база данных, админ-панель `/admin`, терминальный эффект карточек.

Стек: React 19 · TypeScript · Vite · three.js / R3F · GSAP · **Node 24** (встроенный SQLite `node:sqlite`) · Hono.

## Запуск

```bash
npm install
npm run admin:create -- --email you@example.com   # один раз: создать администратора
npm run dev                                        # сайт http://localhost:5180, API :5190
```

Production:

```bash
npm run build      # проверка типов фронтенда и сервера + сборка dist/
npm start          # сервер: dist/ + API на http://127.0.0.1:5181 (PORT переопределяет)
```

Пустая база при первом запуске заполняется демонстрационным контентом (16 услуг, 8 категорий,
4 концепта). Отключить: `SEED_DEMO=0`. Повторно добавить недостающие демо-записи: `npm run db:seed`
(существующие записи не перезаписываются).

## Администратор

Пароля по умолчанию нет. Учётная запись создаётся только на сервере:

```bash
npm run admin:create -- --email you@example.com     # пароль вводится скрыто (мин. 12 символов)
npm run admin:password -- --email you@example.com   # смена пароля, завершает все сессии
npm run admin:list
npm run admin:delete -- --email you@example.com
```

Для автоматизации пароль можно передать в переменной `ADMIN_PASSWORD` (не аргументом).
Вход: `/admin`.

## Админ-панель

- **Обзор** — статистика услуг, категорий, портфолио, новые заявки.
- **Услуги** — поиск, фильтры, публикация/скрытие, удаление с подтверждением; редактор со всеми
  полями (описание, возможности, преимущества, состав работ, обложка с загрузкой, цена
  «индивидуально / фиксированная / от …», текст терминального эффекта, связанные услуги, SEO,
  порядок) и живым предпросмотром карточки и терминала. Ctrl+S — сохранить.
- **Категории** — создание, редактирование, скрытие/восстановление (скрывает и услуги категории).
- **Портфолио** — карточки проектов: реальный кейс или концепт (на сайте помечается как демо).
- **Заявки** — из формы «Контакты»: поиск, фильтр по статусу, карточка заявки, статус, заметка.
- **Настройки сайта** — контакты, ссылки, тексты кнопок и призывов.

Сохранённое сразу видно на сайте (публичный API отдаёт только опубликованное).

## Сервер и данные

```
server/
  index.ts            приложение Hono: API, /uploads, dist + SPA-fallback (npm start)
  env.ts              конфигурация из .env (см. .env.example)
  db/index.ts         SQLite (WAL, внешние ключи), раннер миграций
  db/migrations/      SQL-миграции (применяются автоматически по порядку)
  db/seed.ts          безопасное демо-наполнение (INSERT OR IGNORE)
  repo.ts             доступ к данным
  validation.ts       серверная валидация всех входных данных
  auth.ts             scrypt-хеши паролей, сессии, requireAdmin
  security.ts         CSRF-защита, лимиты, заголовки безопасности
  routes/             public.ts · auth.ts · admin.ts
  cli/                admin.ts · db.ts
src/data/types.ts     модели, общие для сайта, панели и сервера
```

API: `GET /api/catalog`, `/api/projects`, `/api/settings`, `POST /api/leads` — публичные;
`/api/auth/*` — вход/выход; `/api/admin/*` — только после входа (услуги, категории, проекты,
настройки, заявки, загрузка изображений).

Данные — `data/webcraft.db`, загрузки — `data/uploads/` (каталог `data/` не коммитится).
Резервная копия — копия файла БД (при остановленном сервере или через `sqlite3 .backup`).

## Безопасность

- Пароли — scrypt (N=2¹⁵) с солью, сравнение за постоянное время; одинаковый ответ для
  неизвестного email и неверного пароля.
- Сессия — случайный токен в cookie `HttpOnly; SameSite=Strict` (`Secure` в production),
  в БД хранится только его SHA-256. Выход и смена пароля удаляют сессии.
- Все `/api/admin/*` закрыты `requireAdmin`; изменяющие запросы требуют заголовок `X-WebCraft`
  и совпадающий `Origin` (CSRF).
- Лимиты: вход — 8 неудачных попыток с IP / 5 на email за 15 минут; заявки — 5 за 10 минут с IP;
  поле-ловушка для ботов.
- Валидация на сервере, ограничение тела запроса (1 МБ, загрузка — 5 МБ), загружаются только
  PNG/JPG/WebP по сигнатуре файла, случайные имена; ссылки — только https/mailto/tel.
- Заголовки: CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, HSTS в production.

Для публикации в интернете: HTTPS через reverse-proxy, `NODE_ENV=production`, `TRUST_PROXY=1`,
`PUBLIC_ORIGIN=https://ваш-домен`, `HOST=127.0.0.1`.

- `?no-webgl` — режим без 3D; `?reduce-motion` — сокращённые анимации.
